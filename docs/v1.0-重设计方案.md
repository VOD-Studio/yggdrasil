# v1.0 全站重设计方案

> 分支：`v1.0`
> 设计依据：[设计风格与动效体系总结](10-设计风格与动效体系总结.md)
> 范围：前台、后台、编辑器、代码与终端配色、组件图鉴，完整推翻旧设计。

## 已定决策

| 事项 | 决定 |
| --- | --- |
| 范围 | 全站重设计，不保留 Catppuccin、刊物式风格与旧版式。 |
| 品牌色 | 陶土橙 `#d97757` 为唯一强品牌色；不再使用绿色强调。 |
| 世界树元素 | 移除年轮、嫩芽、花园文案、`SproutPlaceholder` 等树木意象。 |
| 站名 | 保留「Yggdrasil」，以纯文字标呈现，不配树木图形。 |
| 字体 | 仅系统字体栈，不加载网页字体。界面与正文用系统黑体；文章标题与大标题用系统衬线（Iowan Old Style + 宋体-简），Windows 中文标题回退微软雅黑。效果稿「字体候选」中的其余七套仅作对照。 |
| 品牌边界 | 借用设计语言，不使用 Anthropic / Claude 的星芒标志或相似图形。 |
| 插画 | 移除线条小狗插画（空状态 18 张与 `xiantiaoxiaogou_*` 输入框装饰），空状态改用线条图标；不引入其他第三方形象。 |
| 流程 | 先出效果稿，定稿后再改 Rust。[效果稿](https://claude.ai/artifact/2ZHVQwYDnDgnTCwdEoKnFg)已覆盖全部页面，清单见下文。 |
| 规范冲突 | 文档第 19 节的两套弹簧参数与 Surface 值，以 `cds-theme.css` / `ClaudeMotionPresets.ts` 的实现值为准，只在 token 源头写一次。 |

## 现状规模

- Rust 中约 1100 处 `paper-*` 类名，覆盖前台和后台。
- `styles/` 下 25 个文件、约 5300 行 CSS。
- Catppuccin 散落在 `themes/*.tmTheme`、`src/bin/generate_highlight_css.rs`、`libs/codemirror-editor/src/themes.ts`、`libs/shared`。
- `public/icons` 使用 Material 图标。

## 迁移策略：并行重建，最后拆旧

1. 先建新 token、动效、图标与组件原语。
2. 临时把旧 `paper-*` 映射到新 token，只保证过渡期未重写页面不崩坏，不作为设计结果。
3. 逐页重写；每完成一页，删除其旧 CSS 与 `paper-*` 类名。
4. 收尾时删除桥接层、`paper-*`、Catppuccin，`rg "paper-|Catppuccin|Sprout"` 零残留。

## 设计体系

### Token

写入 Tailwind v4 `@theme`，直接生成工具类：

- 表面：`surface-0…3`、`popover`。层级靠微亮度差，不靠粗边框。
- 文本：`fg`、`fg-2`、`fg-3`。
- 透明度阶梯：`ink-1…4`（ghost hover、标准边框、强边框、重分割）。
- 品牌与语义：`clay`、`clay-hover`、`clay-soft`、`danger`。
- 边框与阴影：`ring-hairline`（高分屏 0.5px）、`shadow-sm/md/lg/popover/composer`、Clay 双环焦点阴影。
- 圆角：4 / 6 / 8 / 10（面板）/ 12（代码块）/ 16（对话框）/ 20（Composer）/ 胶囊。

明暗两套值按设计文档第 3–6 节；深色模式不是简单反色。为保证正文对比度不低于 4.5:1，效果稿对文档值做了以下调整：

| Token | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| `clay` | `#d97757` | `#d97757` | 只用于圆点、焦点环、进度等装饰，不承载文字。 |
| `clay-fill` | `#b9573a` | `#d97757` | 主按钮底色；浅色配白字，深色配 `#1a0f0a`。 |
| `clay-text` | `#b4532f` | `#e08264` | 强调文字与链接。 |
| `clay-soft` | `#f7e8e1` | `rgba(217,119,87,.15)` | 标记底色、徽标；搜索命中高亮另用 `rgba(217,119,87,.18/.28)`。 |
| `fg-3` | `#6b6b69` | `#8b8984` | 文档原值 `#8a8a8a` / `#666666` 对比度不足。 |
| `surface-0` | `#f5f5f3` | `#0f0f0e` | 深色比文档 `#0b0b0a` 略提亮，避免接近纯黑。 |
| `danger` | `#c93a3a` | `#f87171` | 浅色加深以承载白字。 |

深色文字与表面整体带一点暖调（如 `fg-2 #a9a7a1`），不使用纯中性灰。

### 动效

- `libs/shared/src/spring.ts` 用 `m·x'' + c·x' + k·(x − target) = 0` 求解弹簧，采样为 CSS `linear()`，生成 `styles/motion.css`（`bun run motion-css`）：每档输出缓动 `--ease-spring-*`（同时生成 `ease-spring-*` 工具类）与收敛时长 `--spring-*-duration`。四档为 bouncy（按压、箭头）、snappy（进场、面板、Popover）、gentle（成功反馈）、heavy（抽屉、分割条吸附）。Vitest 校验过冲量、时长，以及入库的 CSS 与参数一致。
- 曲线：`--ease-out-expo`（阴影、焦点、颜色）、`--ease-press`（按压）。
- 纪律：不写 `transition: all`；只动 transform、opacity、box-shadow 等合成属性；动画可被输入打断；`prefers-reduced-motion` 下去掉位移与缩放，仅保留短淡入。

### 页面转场

沿用 `libs/yggdrasil-core` 现有的 View Transitions 架构（`route-transitions.ts` 导航协调、`view-transition-lifecycle.ts` 所有权、`theme-transition.ts` 主题切换、`navigation-scroll.ts` 滚动恢复），只换时长、曲线与样式目标，不重写协调逻辑。

| 过渡 | 现状 | v1.0 |
| --- | --- | --- |
| 普通页面（root） | 240ms `ease` 淡入淡出 | 200ms `--ease-out-expo` 淡入淡出 |
| 栏目切换正文 | 进 300ms 从侧面 24px 滑入，出 160ms；手机 12px | 进用 `--spring-snappy`（约 400ms）、位移 16px；出 140ms `--ease-out-expo`；手机 8px；方向规则不变 |
| 当前栏目指示 | 绿色下划线 300ms 共享过渡 | 改为滑动胶囊，`--spring-snappy`；捕获对象从下划线换成胶囊 |
| 文章标题与封面共享元素 | 360ms，双向匹配，独立降级 | 保留；曲线换 `--spring-snappy`，未匹配时 200ms 淡出 |
| 页头、页脚、后台侧栏 | 独立捕获、只显示新快照 | 不变 |
| 主题切换 | 以点击点为圆心扩散，400ms `ease-out` | 保留；520ms `--ease-out-expo`，扩散背景改为 `surface-0`；外观不变（如切到跟随系统且结果相同）时直接切换 |
| 页内进场 | `page-enter` 400ms、`row-enter` 450ms 等 | 统一 `translateY(8px)` 加淡入，`--spring-snappy`，间隔 40ms，第 6 项后不再延迟 |
| 弹层与对话框 | 150ms / 260ms 固定曲线 | 弹层 `--spring-snappy` 从 0.98 缩放；对话框加 8px 下落；遮罩 150ms 淡入 |

减少动态效果与不支持 View Transitions 时的降级、主题与导航互相打断的处理都保持现状。改动后跑 `libs/yggdrasil-core` 的 Vitest、`scripts/test-view-transitions.cjs` 与首页阅读回归，并按 `scripts/README-view-transitions.md` 手动检查桌面与 390px、明暗主题。

### 字体、图标与配色

- 动态数字一律 `tabular-nums`；深色模式字重补偿；行内图标 `-0.125em` 光学对齐。
- 排版规则（效果稿「排版细节」逐条对照）：

  | 规则 | 实现 |
  | --- | --- |
  | 中文标题不收字距 | 标题 `letter-spacing: 0`；只有纯西文标题（如文字标）保留 `-0.02em` |
  | 中英文自动留空 | 全站 `text-autospace: normal`，不支持的浏览器保持原样；不在内容里补空格 |
  | 行首与连续标点挤压 | 标题与正文 `text-spacing-trim: trim-start` |
  | 均衡断行 | `h1`–`h3` 用 `text-wrap: balance`，正文段落用 `text-wrap: pretty` |
  | 不用中文斜体 | `em` 改为字下着重号（`text-emphasis: filled dot`，位置 `under right`）；`strong` 用 600；全站不对中文用 `font-style: italic`，代码注释除外 |
  | 导语用衬线 | 文章摘要与首页「最新一篇」摘要用标题字体 19px / 1.75、次要色 |
  | 日期用旧式数字 | 文章头与归档日期用标题字体加 `oldstyle-nums`；统计、计数等会变化的数字仍用 `tabular-nums` |
  | 栏目小标签 | 12px、500、`letter-spacing: 0.12em`、`fg-3`，后接一条发丝线 |
  | 每行字数 | 正文栏 `max-width: 38em`（约 38 字），代码块、图片、表格可超出 |
  | Windows 回退 | `--serif` 在宋体之后接 `"Microsoft YaHei"`，避免落到中易宋体 |

  引用块不改：保持标题衬线 18px、次要色与左侧陶土细线，不用楷体。
- 图标换为 Lucide 内联 SVG（ISC，1.5 线宽）：`Icon { name: IconName::Search }`（`src/components/ui/icons.rs`）。图标清单在 `libs/shared/src/icons.ts`，`bun run icons` 从 `lucide-static` 生成 `icons_data.rs`；旧的内联 SVG 与 Material 图标随页面重写逐个替换，P7 删除 `public/icons` 中的 Material 文件。
- 新建暖调语法高亮主题（明暗），一份源生成 `highlight.css`、CodeMirror 主题与 xterm 调色板；Mermaid 接入 token。

### 组件原语

重写 `src/components/ui/`，组件图鉴同步成为设计体系的活文档：

- Button（Primary / Secondary / Ghost / Outline / Danger，XS–LG）、IconButton。
- SegmentedControl：胶囊轨道与滑块，`@container` 窄宽度只留图标。
- Input、Textarea、Composer：`field-sizing: content`，IME 守卫（`isComposing` 与 229），Clay 双环焦点。
- Switch、Checkbox、Chip / Tag、Badge、Panel / Card（单闭合边框）。
- Dialog（focus trap、Esc、焦点归还）、Popover、Menu（roving focus）、Toast。
- ScrollFade、Skeleton、EmptyState、Pagination、Tabs、Breadcrumb。
- 命令面板（⌘K）：前台搜索与跳转，后台执行操作，共用实现。
- Select（展开为 listbox，超过 8 项出现筛选框，不可用项变淡并说明原因）、TimePicker（小时与分钟两列，显示本地时间并换算 UTC）、NumberInput（单位写在框内，越界时边框与说明同时变红）、Tooltip（只给图标按钮补名称或快捷键，悬停 300ms 出现，聚焦立即出现）。
- 退役：`PostCard` 不再有使用处，P7 删除；`CollapsibleSettingsCard` 由「分区目录 + 常开卡片」取代，日志清理、回收站与备份设置统一改写后删除。
- 不出效果稿、直接在图鉴里设计：富文本编辑器细节（选区工具条、表格、代码块语言、上传占位、链接浮层、公式与 Mermaid 编辑预览、脚注、任务列表）在 P1 / P6 完成；后台其余设置分区、备份导入与恢复确认、日志导出与清理策略在 P5 完成，套用已有样式。
- 按规则实现、不单独出图：后台表格通用骨架、搜索面板加载进度点、评论图片上传中 / 提交失败 / 过频提示、写作页已设封面、登录过期跳转提示。

## 前台

### 外壳

- 页头 56px：文字标居左；导航为 ghost 链接，当前项用滑动胶囊标示；右侧为 ⌘K 搜索与主题分段控件（浅色 / 深色 / 跟随系统），所有前台页面一致。滚动后才出现发丝底线与模糊背景。
- 主题切换：明暗外观改变时用 View Transitions 以点击点为圆心做圆形扩散；切到「跟随系统」且外观不变、减少动态效果或浏览器不支持时直接切换。
- 手机（760px 以下）：页头只留文字标、搜索与菜单按钮；菜单为底部抽屉，含栏目、外观分段控件与 RSS 等链接，heavy 弹簧吸附，拖拽 4px 死区，触控目标不小于 44px。
- 手机文章页：顶部 2px 阅读进度；底部悬浮「目录 · 当前小节 · 百分比」，点开为目录抽屉，选中小节后收起。
- 手机搜索：全屏面板，顶部输入框加「取消」，范围标签横向滚动。
- 手机后台：顶栏为菜单、页面标题与 ⌘K；侧栏从左侧滑出（heavy 吸附）；列表改为卡片；主操作为右下角浮动按钮。
- 页脚：单行 © · RSS · 更新日志 · 写作指南 · GitHub 图标（站点设置配置时显示）· 回到顶部。
- 宽度：正文 680px，索引类 880px，图鉴 1152px。

### 首页最新一篇的目录预览

最新一篇面板右侧列出该文的一级小节：标题「本文 N 节」，下面是前 6 个小节标题（两位等宽编号），超出部分显示「还有 M 节」。面板左右以发丝线分隔。

- 数据：现有 `PostListItem` 不含小节信息。首页第 1 页的响应额外返回最新一篇的目录 `{ total, headings: Vec<String> }`，在服务端解析已存储的 `toc_html` 得到一级标题，不在浏览器解析，也不重新渲染 Markdown；随文章列表缓存一起失效。
- 降级：文章没有小节标题时不显示右栏，面板改为单栏，加大标题字号。
- 窄屏：760px 以下隐藏右栏。
- 骨架屏：右栏用 6 行占位，避免数据到达后布局跳动。
- 测试：为 `toc_html` 解析补单元测试，覆盖无标题、只有二级以下标题、超过 6 节和标题含 HTML 实体。

### 搜索面板（⌘K）

页头「搜索 ⌘K」按钮与全局快捷键打开同一个面板。后台复用同一组件，候选项换成后台页面与操作。

**结构**：遮罩（暖灰半透明加 3px 模糊，点击关闭）上方居中一张 640px 宽、距顶 96px、16px 圆角的 popover 面板，最高 560px。自上而下：

1. 输入行（58px）：搜索图标、输入框、有内容时出现清除按钮、`Esc` 键帽。
2. 范围标签：全部 / 文章 / 标签 / 页面；有查询时显示各类命中数。
3. 结果列表：按「文章 · 标签 · 跳转」分组，底部滚动渐隐。全部范围下每组最多 5 / 3 / 3 条，单一范围最多 8 条。
4. 底栏（surface-1）：`↑↓ 选择`、`↵ 打开`、`Esc 关闭`；有查询时右侧为「全文搜索「关键词」→」，链接到 `/search?q=`。

**结果行**：左侧 30px 图标块，中间标题（文章另有一行摘要），右侧元信息（文章日期、标签篇数、页面路径）。命中词用 `<mark>` 标出；摘要截取命中词前后的片段，前后用省略号。当前项整行 `ink-1` 底，图标块浮起，右侧元信息换成 `↵` 键帽。

**状态**：

- 空查询：「最近搜索」（每位访客存在本地，最多 5 条，读写失败时不显示该组）和「跳转」（常用页面与切换主题）。点最近搜索会把词填进输入框。
- 有结果：如上分组。
- 无结果：「没有找到「关键词」」，附「在全文中搜索」按钮。
- 加载中：保留上一次结果，不闪骨架；请求超过 300ms 才在输入行右侧显示细进度点。

**键盘与输入**：

- ⌘K / Ctrl+K 在任何前台页面打开；焦点在可编辑区域时不拦截。打开后焦点进入输入框，关闭后焦点回到触发按钮。面板内 Tab 循环（focus trap）。
- `↑` `↓` 循环移动当前项，`↵` 打开，⌘↵ 在新标签页打开文章，`Esc` 有内容时先清空、再按一次关闭。
- 输入法守卫：组合输入期间（`isComposing` 或 `keyCode === 229`）忽略方向键、回车和 Esc，也不发起查询，`compositionend` 后再查询。
- 鼠标移动（不是 hover 进入）才改变当前项，避免列表滚动时当前项乱跳。
- 无障碍：输入框 `role="combobox"`、`aria-activedescendant` 指向当前项；列表 `role="listbox"`，分组 `role="group"`。

**数据**：标签与页面在浏览器内过滤（标签列表本就有缓存）。文章用新的轻量建议接口：只查标题、摘要与标签，最多返回 8 条，短 TTL 缓存。现有 `search_posts` 走严格限流，不适合逐字查询，所以建议接口另配一档宽松限流。输入防抖 150ms，用请求序号丢弃过期响应；关闭面板时取消未完成的请求。

**动效**：遮罩 150ms 淡入；面板从上方 8px、缩放 0.98 处以 snappy 弹簧进场，关闭 120ms 淡出；当前项底色 120ms 过渡。减少动态效果时只保留淡入淡出。

**窄屏**：640px 以下面板全屏、去掉圆角，隐藏底栏键位提示。

### 笔记

列表页 `/notes` 与阅读页 `/notes/:slug` 共用 880px 容器内的「200px 左栏 + 内容」布局，左栏位置不变，内容从筛选换成目录，进入阅读时布局不跳。

**列表页**：

- 页头：衬线「笔记」、一句介绍、「N 条 · M 个笔记本」。
- 左栏（滚动时吸附）：筛选输入框；类型（全部 / 随记 / 主题笔记，带数量，当前项为浮起样式）；笔记本（按手动编排顺序，带篇数）；常用标签。
- 笔记流按天分组，组标题为「10.15 今天」加发丝线。
  - 随记：无卡片，「时间 + 正文」两列，正文直接渲染（行内代码、链接、图片），下方 `#标签`，悬停时出现「链接」。
  - 主题笔记：surface-2 卡片，顶部「主题笔记」徽标与所属笔记本，衬线标题、两行摘要、「N 节 · 更新于 MM.DD」，悬停时箭头以 bouncy 弹簧右移。
- 底部「更早的记录」按页追加。
- 窄屏：类型横排，笔记本与标签收起。

**阅读页**：

- 左栏为所在笔记本的目录：「← 全部笔记」、笔记本名与简介、按顺序编号的笔记列表。当前篇浮起，并展开本篇小节，正在阅读的小节前有 Clay 圆点。
- 正文：「主题笔记 · 第 3 / 4 篇」、衬线标题、记录与更新时间、标签；正文样式与文章页一致（公式、表格、代码块）。
- 底部「在《笔记本》中继续」，给出本笔记本内的上一篇与下一篇。
- 不在任何公开笔记本中的笔记：左栏只显示「← 全部笔记」与本篇小节。
- 窄屏：左栏隐藏，正文顶部一条「笔记本 · 第 n / m 篇　目录」入口，点开为底部抽屉。

**数据**：现有 `get_note` 不含笔记本上下文，新增公开接口，按 slug 与可选笔记本 ID 返回 `{ notebook, position, total, prev, next, siblings: [{ slug, title }] }`。

- 只考虑公开且未归档的笔记本，同级只列出已发布笔记。
- 一条笔记可属于多个笔记本，阅读页地址带 `?book=<id>` 指明上下文；从笔记本或列表卡片进入时由链接带上。缺省时若只属于一个公开笔记本就用它，否则按无笔记本处理。
- `?book=` 指向笔记不属于、非公开或已归档的笔记本时忽略该参数，不报错。
- 列表卡片的「N 节」从 `toc_html` 解析，与首页目录预览共用解析函数。
- 测试：覆盖多笔记本归属、归档笔记本、未发布的同级笔记被排除、首篇与末篇的上一篇 / 下一篇为空。

## 后台

- 外壳：桌面应用式。左侧栏 surface-1，可折叠、拖拽调宽（heavy 吸附）；主画布 surface-0，内容放 surface-2 面板；去掉 2rem 大圆角外框；顶栏面包屑与 ⌘K。
- 表格：发丝分隔、等宽数字、表头吸顶、`ink-1` 悬停、批量操作条。
- 写作页与笔记编辑器：无干扰编辑、衬线标题、元数据右侧抽屉、保存状态呼吸点；Tiptap 接入 token。
- 仪表盘数字卡片；设置双栏表单分组；日志、运行器、SQL 控制台统一新终端配色。
- 侧栏导航项右侧显示数量（文章、素材、评论），当前项以 Clay 小方点与浮起样式标示；底部为当前用户，进入个人资料。
- 对话框统一为 popover 级面板：16px 圆角、暖灰遮罩加 3px 模糊、snappy 弹簧进场；危险确认用 `alertdialog`，图标与主按钮为 danger。
- 列表批量操作使用底部浮起的工具条，选中行以 `clay` 7% 底色标示。
