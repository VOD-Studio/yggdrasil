# v1.0 全站重设计方案

> 分支：`v1.0`
> 设计依据：[设计风格与动效体系总结](10-设计风格与动效体系总结.md)
> 范围：前台、后台、编辑器、代码与终端配色、组件图鉴，完整推翻旧设计。

## 已定决策

| 事项 | 决定 |
| --- | --- |
| 范围 | 全站重设计，不保留 Catppuccin、刊物式风格与旧版式。 |
| 品牌色 | 陶土橙 `#d97757` 为唯一强品牌色；不再使用绿色强调。 |
| 世界树元素 | 移除年轮、嫩芽、花园文案、`SproutPlaceholder` 等树木意象。 |
| 站名 | 保留「Yggdrasil」，以纯文字标呈现，不配树木图形。 |
| 字体 | 仅系统字体栈。UI 用无衬线；文章标题与大标题用系统衬线营造编辑温度。 |
| 品牌边界 | 借用设计语言，不使用 Anthropic / Claude 的星芒标志或相似图形。 |
| 流程 | 先出静态 HTML 效果稿（首页、文章页、后台外壳，明暗两版），定稿后再改 Rust。 |
| 规范冲突 | 文档第 19 节的两套弹簧参数与 Surface 值，以 `cds-theme.css` / `ClaudeMotionPresets.ts` 的实现值为准，只在 token 源头写一次。 |

## 现状规模

- Rust 中约 1100 处 `paper-*` 类名，覆盖前台和后台。
- `styles/` 下 25 个文件、约 5300 行 CSS。
- Catppuccin 散落在 `themes/*.tmTheme`、`src/bin/generate_highlight_css.rs`、`libs/codemirror-editor/src/themes.ts`、`libs/shared`。
- `public/icons` 使用 Material 图标。

## 迁移策略：并行重建，最后拆旧

1. 先建新 token、动效、图标与组件原语。
2. 临时把旧 `paper-*` 映射到新 token，只保证过渡期未重写页面不崩坏，不作为设计结果。
3. 逐页重写；每完成一页，删除其旧 CSS 与 `paper-*` 类名。
4. 收尾时删除桥接层、`paper-*`、Catppuccin，`rg "paper-|Catppuccin|Sprout"` 零残留。

## 设计体系

### Token

写入 Tailwind v4 `@theme`，直接生成工具类：

- 表面：`surface-0…3`、`popover`。层级靠微亮度差，不靠粗边框。
- 文本：`fg`、`fg-2`、`fg-3`。
- 透明度阶梯：`ink-1…4`（ghost hover、标准边框、强边框、重分割）。
- 品牌与语义：`clay`、`clay-hover`、`clay-soft`、`danger`。
- 边框与阴影：`ring-hairline`（高分屏 0.5px）、`shadow-sm/md/lg/popover/composer`、Clay 双环焦点阴影。
- 圆角：4 / 6 / 8 / 10（面板）/ 12（代码块）/ 16（对话框）/ 20（Composer）/ 胶囊。

明暗两套值按设计文档第 3–6 节；深色模式不是简单反色。

### 动效

- 在 `libs` 中用 `m·x'' + c·x' + k·(x − target) = 0` 求解弹簧，采样为 CSS `linear()`，同时输出收敛时长：`--spring-bouncy`（按压、箭头）、`--spring-snappy`（进场、面板、Popover）、`--spring-gentle`（成功反馈）、`--spring-heavy`（抽屉、分割条吸附）。用 Vitest 校验过冲量与时长。
- 曲线：`--ease-out-expo`（阴影、焦点、颜色）、`--ease-press`（按压）。
- 纪律：不写 `transition: all`；只动 transform、opacity、box-shadow 等合成属性；动画可被输入打断；`prefers-reduced-motion` 下去掉位移与缩放，仅保留短淡入。

### 字体、图标与配色

- 动态数字一律 `tabular-nums`；深色模式字重补偿；行内图标 `-0.125em` 光学对齐。
- 图标换为 Lucide 内联 SVG（ISC，1.5 线宽）。
- 新建暖调语法高亮主题（明暗），一份源生成 `highlight.css`、CodeMirror 主题与 xterm 调色板；Mermaid 接入 token。

### 组件原语

重写 `src/components/ui/`，组件图鉴同步成为设计体系的活文档：

- Button（Primary / Secondary / Ghost / Outline / Danger，XS–LG）、IconButton。
- SegmentedControl：胶囊轨道与滑块，`@container` 窄宽度只留图标。
- Input、Textarea、Composer：`field-sizing: content`，IME 守卫（`isComposing` 与 229），Clay 双环焦点。
- Switch、Checkbox、Chip / Tag、Badge、Panel / Card（单闭合边框）。
- Dialog（focus trap、Esc、焦点归还）、Popover、Menu（roving focus）、Toast。
- ScrollFade、Skeleton、EmptyState、Pagination、Tabs、Breadcrumb。
- 命令面板（⌘K）：前台搜索与跳转，后台执行操作，共用实现。

## 前台

### 外壳

- 页头 56px：文字标居左；导航为 ghost 链接，当前项用滑动胶囊标示；右侧为 ⌘K 搜索与主题分段控件（浅色 / 深色 / 跟随系统）。滚动后才出现发丝底线与模糊背景。
- 手机：底部抽屉，heavy 弹簧吸附，拖拽 4px 死区。
- 页脚：单行 © · RSS · 更新日志 · 写作指南。
- 宽度：正文 680px，索引类 880px，图鉴 1152px。

### 页面

| 页面 | 设计 |
| --- | --- |
| 首页 | 「书桌」：状态行（Clay 呼吸点、最近更新、篇数）→ 衬线标题（读站点设置）→ Composer 搜索与常用标签 → 最新一篇面板 → 按「年 · 月」分组的索引 → 尾部三格（最近笔记、常去标签、去别处走走）。第 2 页起只有页标题和索引。 |
| 文章页 | 衬线标题、等宽元信息；正文 680px；宽屏右侧目录带滚动渐隐，窄屏收进 Popover；代码块 12px 发丝线；评论用 Composer；底部上一篇 / 下一篇。 |
| 归档、标签 | 大号等宽年份分组，行样式与首页索引一致，标签筛选用 Chip。 |
| 搜索 | 顶部 Composer，命中词 `clay-soft` 底色，键盘上下选择。Search 路由支持 `?q=`。 |
| 笔记 | 笔记本侧栏（surface-1）加内容区（surface-0），列表滚动渐隐。 |
| 友链、关于、更新日志、写作指南 | 面板网格；单栏编辑排版；时间线加版本 Chip；文档式布局。 |
| 登录、注册、404 | 居中 popover 级面板；404 一句话加返回入口。 |

## 后台

- 外壳：桌面应用式。左侧栏 surface-1，可折叠、拖拽调宽（heavy 吸附）；主画布 surface-0，内容放 surface-2 面板；去掉 2rem 大圆角外框；顶栏面包屑与 ⌘K。
- 表格：发丝分隔、等宽数字、表头吸顶、`ink-1` 悬停、批量操作条。
- 写作页与笔记编辑器：无干扰编辑、衬线标题、元数据右侧抽屉、保存状态呼吸点；Tiptap 接入 token。
- 仪表盘数字卡片；设置双栏表单分组；日志、运行器、SQL 控制台统一新终端配色。
