# Yggdrasil 界面设计规范

> 依据：2026-10-23 的 `master` 代码。描述已经实现的界面、配色、排版与动效，以代码为准。
> 设计来源与迁移过程见 [v1.0 全站重设计方案](v1.0-重设计方案.md)；[设计风格与动效体系总结](10-设计风格与动效体系总结.md) 是外部参考资料，记录的不是本仓库的实现。
> 配套技能：[skills/yggdrasil-ui-design/SKILL.md](skills/yggdrasil-ui-design/SKILL.md)。

## 1. 设计取向

界面应当安静、温润、可信，读起来像一本现代编辑器，不追求科技感。

- **暖灰纸面**：页面底色是暖灰，内容放在近白表面上。深色模式也保留一点暖调，不做简单反色。
- **唯一强品牌色**：陶土橙 `#d97757`（clay）只出现在焦点、确认、激活、进度和少量强调处，不用作大面积背景。
- **层级靠亮度差**：表面之间用微弱的亮度差、发丝线和很淡的阴影区分，不用粗边框或重投影。
- **系统字体**：不加载网页字体。界面和正文用系统黑体，标题与导语用系统衬线。
- **有质量的动效**：缓动由弹簧物理方程求解生成，只改变合成属性，可被打断，并尊重「减少动态效果」。
- **交互防御**：照顾输入法组合、拖拽死区、焦点归还、窄容器和触屏。
- **品牌边界**：站名「Yggdrasil」只用纯文字标（文字后接一个陶土方点），不配树木图形，不使用 Anthropic / Claude 的标志或相似图形，也不放第三方形象插画。

## 2. 单一来源与生成链

每个值只在源头写一次。生成文件不要手改。

| 内容 | 源头 | 生成物 / 消费方 |
| --- | --- | --- |
| 颜色、字体、阴影、圆角、曲线 | `styles/theme.css`（`@theme static`，深色值写在 `.dark` 覆盖块） | Tailwind 工具类，如 `bg-surface-2`、`text-fg-3`、`ring-hairline`、`rounded-panel`、`shadow-popover` |
| 弹簧缓动 | `libs/shared/src/spring.ts` 的 `SPRING_PRESETS` | `cd libs/shared && bun run motion-css` 生成 `styles/motion.css`（`--ease-spring-*`、`--spring-*-duration`、`ease-spring-*` 工具类） |
| 代码配色 | `libs/shared/src/code-palette.ts` | `bun run code-themes` 生成 `themes/Yggdrasil {Light,Dark}.tmTheme` 与 `libs/tiptap-editor/src/code-highlight.css`；`make highlight-css` 再生成 `public/highlight.css`；CodeMirror、xterm 主题直接读调色板 |

## 3. 颜色

### 3.1 表面

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `surface-0` | `#f5f5f3` | `#0f0f0e` | 页面底、后台主画布、主题扩散底色 |
| `surface-1` | `#fafaf8` | `#161615` | 后台侧栏、代码块、表头、面板底栏 |
| `surface-2` | `#ffffff` | `#1a1a19` | 卡片、面板、导航当前项 |
| `surface-3` | `#ffffff` | `#20201e` | 浮起卡片、Composer、深色下的当前项 |
| `popover` | `#ffffff` | `#222220` | 弹层、菜单、对话框、抽屉、批量操作条 |

层级规则：页面最暗（离读者最远），越靠前的层越亮。深色 `surface-0` 比纯黑略亮。

### 3.2 文本

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `fg` | `#151515` | `#f2f1ee` | 标题、主文本、表格首列 |
| `fg-body` | `#2b2b29` | `#dad8d2` | 长文正文 |
| `fg-2` | `#525252` | `#a9a7a1` | 次级文本、导航默认态、导语、引用 |
| `fg-3` | `#6b6b69` | `#8b8984` | 弱文本、元信息、表头、栏目小标签、占位 |

`fg-3` 比参考稿更深，保证对比度不低于 4.5:1。

### 3.3 透明度阶梯与发丝线

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `ink-1` | `rgb(0 0 0 / .045)` | `rgb(255 255 255 / .05)` | ghost 悬停、行悬停、行内代码底、次要按钮底 |
| `ink-2` | `/.08` | `/.09` | 次要按钮悬停、`aria-pressed`、骨架高光、禁用发送键 |
| `ink-3` | `/.12` | `/.14` | 强边框、输入框悬停、滚动条滑块 |
| `ink-4` | `/.18` | `/.2` | 重分割、任务列表复选框边、默认状态点 |
| `hairline` | `rgb(0 0 0 / .09)` | `rgb(255 255 255 / .09)` | 发丝线颜色 |

发丝线宽度是 `--hairline`：普通屏 1px，`min-resolution: 2dppx` 高分屏 0.5px。边框一律写成 `inset 0 0 0 var(--hairline) var(--color-hairline)` 的阴影环，或用 `ring-hairline`，不写 `border: 1px solid` 粗边。

### 3.4 品牌色 clay

| Token | 浅色 | 深色 | 只用于 |
| --- | --- | --- | --- |
| `clay` | `#d97757` | `#d97757` | 装饰：圆点、方点、焦点环、进度环 / 条、拖拽线、引用竖线、着重号 |
| `clay-hover` | `#c4633f` | `#e28a6c` | clay 装饰的悬停 |
| `clay-fill` | `#b9573a` | `#d97757` | 主按钮、发送键、手机浮动按钮、已勾选任务框的底色 |
| `on-clay` | `#ffffff` | `#1a0f0a` | `clay-fill` 上的文字与图标 |
| `clay-text` | `#b4532f` | `#e08264` | 强调文字、正文链接、脚注引用 |
| `clay-soft` | `#f7e8e1` | `rgb(217 119 87 / .15)` | 徽标、待审计数、头像首字底、时间选择器选中格、「提示」告示框 |

纪律：

- `clay` 不承载文字；文字用 `clay-text`，按钮底用 `clay-fill` 配 `on-clay`。
- 主按钮悬停为 `color-mix(clay-fill 90%, fg)`，不另取色。
- 衍生透明度只用这些：文本选区 `.22`（深色 `.3`）；搜索命中 `<mark>` `.18`（深色 `.28`）；表格选中行、素材选中瓦片 `color-mix(clay 7%, transparent)`；正文链接下划线 `color-mix(clay 40%)`。

### 3.5 语义色

| Token | 浅色 | 深色 | 软底（浅 / 深） |
| --- | --- | --- | --- |
| `danger` | `#c93a3a` | `#f87171` | `#fbeaea` / `rgb(248 113 113 / .14)` |
| `success` | `#2f6f4f` | `#8fcfae` | `#e7f1ea` / `rgb(143 207 174 / .12)` |
| `warning` | `#8a5a0b` | `#e8c27a` | `#f6ecd8` / `rgb(232 194 122 / .13)` |

`on-danger` 浅色为白、深色为 `#1f0b0b`。危险色只用于破坏性操作和错误，不与 clay 混用。

### 3.6 遮罩与模糊

| 位置 | 取值 |
| --- | --- |
| 对话框 `.dialog-overlay` | `rgb(15 15 14 / .38)`，深色 `rgb(0 0 0 / .6)`，加 `blur(3px)` |
| 命令面板 `.palette-scrim` | `rgb(28 26 22 / .28)` + `blur(3px)` |
| 底部抽屉 `.sheet-scrim` | `rgb(28 26 22 / .24)`，深色 `rgb(0 0 0 / .55)` |
| 前台页头、后台顶栏、更新日志导航 | `color-mix(surface-0 82%, transparent)` + `blur(12px)` |

全站只有以上带模糊的几处用 `backdrop-filter`，不要再加玻璃拟态。

### 3.7 代码配色

一份调色板（`libs/shared/src/code-palette.ts`）同时驱动服务端 syntect 高亮、Tiptap、CodeMirror 和 xterm，rustdoc 主题（`rustdoc-theme/css/tokens.css`）手动同步。配色移植自 [clay.nvim](https://github.com/DefectingCat/clay.nvim) 的 Clay 设计规范（restrained 模式）：层级靠亮度而不是色相，除字符串的暖灰和函数定义的陶土色外都是 R = G = B 的中性灰。用户写的东西对比最强，语言结构退后，注释最弱。

| 角色 | 浅色 | 深色 | 对比度（代码块底） | 用于 |
| --- | --- | --- | --- | --- |
| 背景 | `#fafaf8` | `#161615` | | 等于 `surface-1` |
| `bright` | `#151515` | `#f2f1ee` | 17.5 / 16.0 | 标题、新增行、无效代码；等于 `fg` |
| `foreground` | `#2b2b29` | `#dad8d2` | 13.6 / 12.7 | 变量、模块；等于 `fg-body` |
| `secondary` | `#3e3e3e` | `#bebebe` | 10.2 / 9.7 | 类型、常量、数字、布尔、成员、标签名、转义、键名、修改行 |
| `string` | `#56433c` | `#c2afa8` | 8.9 / 8.6 | 字符串、正则、行内代码；色相取自 Clay |
| `muted` | `#4f4f4f` | `#a7a7a7` | 7.8 / 7.5 | 关键字、函数调用、参数、内置变量、注解、宏、删除行 |
| `comment` | `#5c5c5c` | `#989898` | 6.4 / 6.3 | 注释、文档注释、引用 |
| `subtle` | `#6a6a6a` | `#898989` | 5.2 / 5.2 | 标点、运算符、内置函数 |
| `clay` | `#b4532f` | `#e08264` | 4.8 / 6.5 | 函数定义；等于 `clay-text` |
| 行号 | `#6b6b69` | `#8b8984` | | 等于 `fg-3` |
| 选区 / 光标 | `rgba(217,119,87,.22)` / `#d97757` | `rgba(217,119,87,.3)` / `#d97757` | | |

- **对比度下限 4.5:1**：所有语法色在浅色 `surface-0/1/2`、深色 `surface-0/1/3` 上都不低于 4.5:1。Clay 的注释（4.4）和标点（3.4）达不到，于是把 `foreground` 到 `subtle` 的阶梯按 Clay 的对数对比度比例压缩到 5.15:1 为止，两个变体在代码块底色上对比度一致。
- **Clay 只给函数定义**：函数调用与关键字同为 `muted`。函数定义用 `clay-text`，品牌色在浅色底上只有 3:1，不承载文字。
- **Diff 不用红绿**：新增 `bright`、删除 `muted`、修改 `secondary`，靠 `+`/`-` 符号和亮度区分。
- **样式**：注释不用斜体（中文没有真斜体）；粗体只给标题；链接加下划线。
- **终端**：ANSI 16 色按 Clay 的终端表映射回灰阶，red 用 `clay`，green 用 `bright`。
- `code-palette.test.ts` 校验对比度下限、阶梯顺序和中性灰。

高亮 CSS 剥掉 syntect 自带的背景，代码块背景由 `surface-1` 提供；终端背景同为 `surface-1`。

## 4. 字体与排版

### 4.1 字体栈

| Token | 栈 | 用途 |
| --- | --- | --- |
| `--font-sans` | `-apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei", sans-serif` | 界面与正文 |
| `--font-serif` | `"Iowan Old Style", Georgia, "Songti SC", "Noto Serif SC", "Source Han Serif SC", STSong, "Microsoft YaHei", serif` | 文章与页面大标题、导语、引用、日期、年份 |
| `--font-mono` | `ui-monospace, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace` | 代码、键帽、月份标签、运行器语言、脚注编号 |

`--font-sans` 覆盖了 Tailwind 默认栈：默认栈没有中文黑体，会让中文回退到系统衬线。衬线栈在宋体之后接微软雅黑，避免 Windows 落到中易宋体。

### 4.2 全局排版规则

| 规则 | 实现 |
| --- | --- |
| 中英文自动留空 | `body { text-autospace: normal }`，内容里不手动补空格 |
| 行首标点挤压 | `text-spacing-trim: trim-start` |
| 均衡断行 | `h1`–`h3` 用 `text-wrap: balance`，`p` 用 `text-wrap: pretty` |
| 中文标题不收字距 | 标题 `letter-spacing: 0`；只有纯西文文字标用 `-0.01em` |
| 不用中文斜体 | 正文 `em` 改为陶土色着重号：`text-emphasis: filled dot`，位置 `under right`；`strong` 用 600 |
| 数字 | 统计、计数、页码、表格、时间等会变化的数字用 `tabular-nums`；文章头与归档日期用衬线加 `oldstyle-nums` |
| 行内图标 | `.icon-inline { vertical-align: -0.125em }` 做光学对齐 |
| 栏目小标签 | `.section-label`：12px、500、`letter-spacing: .12em`、`fg-3`，后接一条发丝线 |
| 渲染 | `-webkit-font-smoothing: antialiased`；深色模式没有额外的字重补偿 |

### 4.3 文章正文（`.post-content`）

| 元素 | 规格 |
| --- | --- |
| 正文 | 16.5px / 1.9 / `fg-body`；767px 以下 16px / 1.85 |
| `h1`–`h3` | 衬线 500，行高 1.4，分别为 1.7em / 1.5em / 1.2em，外边距 `2.2em 0 .8em` |
| `h4`–`h6` | 黑体 600，行高 1.5；`h5`、`h6` 为 .9em `fg-2` |
| 链接 | `clay-text`，1px 下划线（clay 40%），`text-underline-offset: 4px` |
| 行内代码 | `ink-1` 底，.84em，内边距 `.14em .42em`，5px 圆角 |
| 引用 | 衬线 1.09em / 1.8，`fg-2`，左侧 2px clay 竖线，不用楷体 |
| 告示框 | 10px 圆角，.91em 黑体，中文标签（说明 / 提示 / 重要 / 注意 / 警告）分别配 success / clay / warning / danger 软底 |
| 代码块 | 12px 圆角，`surface-1`，内嵌发丝线，代码 .82em / 1.75；复制按钮 30px，悬停或聚焦时显示，触屏常显 |
| 表格 | 10px 圆角加发丝线环，.85em，`tabular-nums`；表头 `surface-1` / `fg-3` / 500 |
| 图片 | 10px 圆角，`zoom-in` 光标；深色下 `brightness(.9)` |
| 折叠块 | `surface-2`，10px 圆角，自绘箭头用 bouncy 弹簧旋转 |
| 任务列表 | 1em 复选框，1.5px `ink-4` 边，勾选后为 `clay-fill` 底 |

每行字数：文字在 680px 文章栏内左右各缩进 `--post-inset`（26px，约 38 字）。直属正文的代码块、运行器、表格、站内图片在 768px 及以上对称外扩回 680px；767px 以下缩进归零，代码块与运行器贴屏幕边、去圆角。

## 5. 形状、阴影与焦点

| 圆角 | 值 | 用途 |
| --- | --- | --- |
| `rounded-sm` / `md` / `lg` | 4 / 6 / 8px | 小件；按钮 8px，XS 按钮 6px |
| `rounded-panel` | 10px | 面板、卡片、表格、图片、告示框、LG 按钮、下拉面板 |
| `rounded-code` | 12px | 代码块、运行器、空状态图标块 |
| `rounded-dialog` | 16px | 对话框、命令面板、登录面板 |
| `rounded-composer` | 20px | Composer、底部抽屉上沿；小号 Composer 为 14px |
| `rounded-full` | 胶囊 | 导航当前项、Chip、分段控件 |

| 阴影 | 浅色 | 用途 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px / .04` | 浮起的当前项 |
| `shadow-md` | 两层，最深 `/.05` | 卡片悬浮 |
| `shadow-lg` | `0 12px 32px / .08` | 大浮层 |
| `shadow-composer` | `0 4px 20px / .035` | Composer |
| `shadow-popover` | 发丝线环 + `0 12px 32px / .1` | 弹层、菜单、下拉、抽屉、批量操作条 |
| `shadow-focus` | `inset 1px surface-1` + `1.5px clay` 外环 + `6px` clay 光晕 | 所有可聚焦控件 |

深色阴影的透明度提高到 `.3`–`.5`。

焦点规则：一律 `outline: none` 加 `box-shadow: var(--shadow-focus)`（clay 双环）。`aria-invalid` 的输入框改成 `1.5px danger` 环。菜单项聚焦时用 `ink-1` 底，不画环。文字链接型 Chip 用 `outline-2 outline-offset-4 outline-clay`。

## 6. 布局

### 6.1 宽度与断点

| 容器 | 宽度 |
| --- | --- |
| 页头、页脚、索引类页面主区 | 880px |
| 文章页外框 | 1240px：`1fr / minmax(0,680px) / 1fr` 三栏，栏间 56px；1099px 以下为单栏 680px |
| 正文栏 | 680px |
| 组件图鉴 | 1152px（`max-w-6xl`） |
| 笔记 | 880px 内为 200px 左栏加内容，间距 2.5rem，左栏 `sticky top: 5.5rem` |
| 搜索弹层 / 404 | 640px / 560px |
| 登录面板 | 26rem |

主要断点：**767px**（手机形态统一在此切换，与 Tailwind `md:` 一致：页头、抽屉、后台顶栏变为手机形态，`--site-header-height` 从 56px 改为 52px；正文字号、`--post-inset`、归档单栏、目录变抽屉同样在此切换）、**640px**（命令面板全屏去圆角）、**1099 / 1100px**（目录变为正文右侧吸顶栏）、**480px**（登录面板内边距）。其余页面局部断点见各页样式。

### 6.2 前台外壳

- 页头 56px，`sticky top-0 z-40`。左侧文字标（15px / 600，后接 7px clay 方点），中间 ghost 导航（首页、笔记、归档、友链、关于），右侧「搜索 ⌘K」与外观分段控件（浅色 / 深色 / 跟随系统）。
- 导航当前项是 999px 胶囊 `.nav-indicator`：`surface-2`（深色 `surface-3`）加发丝线环和 `shadow-sm`。
- 页头底线与模糊随滚动出现：支持 `animation-timeline: scroll()` 时，在 0–24px 滚动范围内从透明渐变到 82% 底色、12px 模糊和发丝底线；不支持时始终显示。
- 767px 以下页头只留文字标、搜索和菜单按钮（44px 触控目标）；菜单为底部抽屉，内含栏目、外观分段控件和 RSS 等链接。抽屉项高 48px，当前项为 `ink-1` 底加 6px clay 圆点。

## 8. 动效

### 8.1 原则

- 只动 `transform`、`opacity`、`box-shadow`、`clip-path` 等合成属性；不写 `transition: all`。
- 动画可被新输入打断，不排队。
- 入场使用弹簧缓动，退出更短、用 `--ease-out-expo`，且不带回弹。
- 颜色、阴影、焦点等状态变化用 150–220ms `--ease-out-expo`。
- 减少动态效果时去掉位移与缩放，只保留短淡入或直接切换。

### 8.2 弹簧四档

弹簧由 `m·x'' + c·x' + k·(x − 1) = 0` 求解，在收敛时长内取 40 个采样点，写成 CSS `linear()`。偏差小于 0.005 视为静止。

| 档位 | k · c · m | 阻尼比 ζ | 过冲 | 时长 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `bouncy` | 600 · 30 · 1 | 0.612 | 8.8% | 370ms | 按钮松开回弹、开关圆点、复选框对勾、展开箭头、折叠块箭头 |
| `snappy` | 320 · 28 · 1 | 0.783 | 1.9% | 410ms | 页面与分块进场、弹层、菜单、下拉、对话框、Toast、分段滑块、导航胶囊、栏目切换 |
| `gentle` | 380 · 18 · 1 | 0.462 | 19.5% | 600ms | 复制成功、点赞等正反馈 |
| `heavy` | 1200 · 80 · 0.1 | 3.651 | 0% | 350ms | 抽屉、侧栏宽度、分割条吸附 |

固定曲线：`--ease-out-expo: cubic-bezier(.16, 1, .3, 1)` 用于颜色、阴影、焦点、退出和淡化；`--ease-press: cubic-bezier(.2, 0, 0, 1)` 只用于按下。

在 CSS 中写成 `animation: x var(--spring-snappy-duration) var(--ease-spring-snappy)`。在 JS 中读取时要换算单位：压缩后的 CSS 会把 `410ms` 序列化成 `.41s`，所以写作 `parseFloat(d) * (d.endsWith('ms') ? 1 : 1000)`。

### 8.3 进场与开合

| 类 / 场景 | 动画 | 填充模式 |
| --- | --- | --- |
| `.animate-page-enter` | `translateY(8px)` + 淡入，snappy | `backwards` |
| `.page-enter` | 同上，按 `--enter-index` 每项错开 40ms，序号封顶 5 | `backwards` |
| `.home-enter`（首页） | `translateY(12px)` + 淡入，600ms `--ease-out-expo`，内联 `--home-delay` 每项 45ms，封顶 5 | `backwards` |
| `.animate-popover-enter(-edge)` | 从 `scale(.98)` 淡入，snappy | `both` |
| `.animate-select-enter` / listbox / menu / Toast | `translateY(-4px) scale(.98)` 淡入，snappy | `both` |
| 对话框 | 遮罩 150ms `--ease-out-expo` 淡入；面板从 `translateY(-8px) scale(.98)` 以 snappy 进场；关闭时加 `.is-closing`，200ms 淡出并缩到 `.97`，Rust 侧 `EXIT_ANIM_MS = 200` 后卸载 | `backwards` |
| 命令面板 | 遮罩 150ms 淡入，面板 snappy 进场，关闭 120ms 淡出，当前项底色 120ms 过渡 | — |
| 底部抽屉 | `translateY(100%)` 以 heavy 弹簧进场，关闭 200ms `--ease-out-expo`；拖动时 `animation: none`，跟手 | — |
| 后台侧边抽屉 | `translateX(-100%)` 以 heavy 弹簧进场，关闭 200ms | — |
| Tooltip | 透明度 150ms，4px 位移 220ms `--ease-out-expo` | — |
| 分段滑块 | 位置与尺寸用 snappy，透明度 150ms；变化后 30ms 测量，`ResizeObserver` 跟随 | — |

选择填充模式：终态就是元素自然值的入场动画用 `backwards`。`forwards` 会以单位矩阵的形式残留 `transform`，让元素成为 `fixed` 后代的包含块（目录栏曾因此被钉在文章中部）。从非自然状态开始、需要保持首帧的弹层用 `both`。

同一次挂载如果已经由原生页面过渡接管，`page-entry.ts` 会标记 `data-vt-enter-handled`，CSS 关掉页内入场动画，避免播放两次；弹层、对话框等交互动画不受影响。

### 8.4 页面转场（View Transitions）

由 `libs/yggdrasil-core` 统一协调：`route-transitions.ts` 负责导航，`view-transition-lifecycle.ts` 保证同一时刻只有一个过渡，`theme-transition.ts` 负责主题切换，`navigation-scroll.ts` 恢复滚动。等待目标页就绪最多 300ms。

| 过渡 | 规格 |
| --- | --- |
| 普通页面（root） | 200ms `--ease-out-expo` 交叉淡入淡出；跨文档用 `@view-transition { navigation: auto }`。前台只有文章标题或封面参与共享过渡时才用整页过渡，另有后台、登录与跨外壳导航 |
| 前台正文 | 前台外壳内没有共享元素的导航（栏目、文章、分页、标签、笔记、更新日志等）只捕获最外层 `main`，页头保持实时。旧正文快照保持原尺寸和原位置（滚动位置、更宽的文章栏），用 `clip-path` 让出页头区域、左右和底部不裁。两个不同栏目之间：新内容按方向从 16px 外以 snappy 滑入，旧内容反向移出半程；767px 以下位移 8px。其余导航原地淡入淡出，不位移。透明度与位移分开：新旧内容用同一条 140ms `--ease-out-expo` 互补淡入淡出，合计不透明度恒为 1，中途不露底色 |
| 导航胶囊 | 不做快照。在 `vt.ready` 之后，用 WAAPI 在实时 DOM 中从旧胶囊位置滑到新位置（snappy），因为带 `view-transition-name` 的元素在过渡期间不可点击，快照也会盖住导航文字。进入搜索页时在原栏目处 140ms 淡出，从搜索页或文章回到栏目时以 snappy 淡入。 |
| 文章标题与封面 | 共享元素，按 `data-vt-post-id` 双向匹配，410ms snappy；未匹配时 200ms 淡出；封面要等图片解码完成才参与 |
| 页头、页脚、后台侧栏 | 整页过渡中单独捕获，`animation: none`，只显示新快照；前台正文过渡中页头不捕获 |
| 主题切换 | 以点击点为圆心做圆形扩散：`clip-path: circle()` 从 0 扩到最远角距离，520ms `--ease-out-expo`，新快照底色为 `surface-0`；键盘触发时以视口中心为圆心。外观不变（如切到「跟随系统」且结果相同）时直接切换；系统偏好变化时也瞬间切换 |

过渡中再次导航（快速连点栏目）：

- 动画播放中（`vt.ready` 之后）：不跳过当前过渡、不重新截图，直接提交新路由（接力）。新快照是实时画面，新页面渲染后在其中直接替换；仍在显示的旧页面保留 `data-vt-enter-handled`，不重播进场；胶囊从当前位置滑向新栏目。若跳过当前过渡，刚进入的页面会跳回全亮、被截成旧快照冻住，再淡出一次。新页面 300ms 内仍未渲染，按分包迟到处理（跳过过渡、旧正文淡出）。
- 截图后、`vt.ready` 之前（浏览器暂停绘制、等目标页渲染）：这时的站内跳转先记下，只保留最新一次，`ready` 后接力。这是「动画可被新输入打断，不排队」的唯一例外，最多等 300ms。
- 过渡期间命中测试会落到 `<html>`（截图后到 `ready` 之间，以及 root 过渡的整段动画），点击协调器按坐标在 `[data-vt-shell]` 外壳里找回被点的链接。同一原因下，被点链接在截图那一帧会失去 `:hover`，这一帧冻结显示到 `ready`；协调器在截图前给它挂 `data-vt-pressed`，`.nav-item` 据此保持悬停色，过渡结束、取消或被接力时撤掉。

主题切换的顺序：先在过渡回调里同步通知 CodeMirror、xterm 这类命令式主题组件，再切换 `.dark`，并等待 Mermaid 这类异步渲染完成，保证新快照已经是新配色。

降级：浏览器不支持 View Transitions 时直接提交，并恢复滚动位置；开启减少动态效果时 JS 不发起过渡，CSS 把所有 `::view-transition-*` 动画时长设为 0。

### 8.5 滚动驱动

- 页头和后台顶栏：底色、模糊、底线在 0–24px 范围内渐显。
- `.scroll-fade-y` / `.scroll-fade-x`：用 `mask-image` 渐隐边缘（`--fade-size: 1.25rem`），并随滚动位置开关首尾渐隐（需要 `@property` 注册 `--fade-start/end`）。
- 阅读进度：`toc-sidebar.ts` 用 rAF 节流写入 `--toc-progress`（0–1），供进度条 `scaleX`、进度环 `stroke-dasharray`、手机 2px 阅读线与百分比文字共用。
- 规则：滚动时间线在路由替换正文那一帧可能失效。基础样式必须是「未滚动」态，关键帧只写 `to` 终态，失效时才不会露出错误状态。
- 锚点跳转：`scroll-to-heading.ts` 手动滚动并预留页头高度加 16px，减少动态效果时不平滑。

### 8.6 其他动效

- 循环动画：骨架扫光 1.4s，首页状态呼吸点 2.4s，运行器运行中 1.2s，按钮 spinner 800ms（减少动态效果时放慢到 2400ms）。
- 卡片与行悬停：颜色和底色 150–220ms；箭头右移用 bouncy 弹簧，或 270ms snappy 曲线。
- 灯箱与 Mermaid 放大：FLIP 飞行 250ms ease-out，先强制回流并等两帧 rAF 再开始；缩放和旋转 180–200ms；相册切换 150ms 淡出淡入；控件 2.5 秒后自动隐藏；滚动超过 120px 关闭；每个 `transitionend` 都配兜底计时器。
- 更新日志目录指示器：320ms `--ease-out-expo`。

### 8.7 减少动态效果

分三层实现：

1. JS：`@yggdrasil/shared` 的 `prefersReducedMotion()` 拦住路由过渡、主题扩散、页内入场标记和平滑滚动。
2. CSS：`styles/pages/navigation-motion.css` 关闭所有入场类的动画，`html` 改为 `scroll-behavior: auto`；弹层、菜单、Toast、命令面板换成 120–150ms 线性淡入；对话框关闭只保留 200ms 淡出；按钮去掉缩放；骨架停止扫光；分段滑块只保留透明度。
3. View Transitions：所有 `::view-transition-*` 动画时长为 `0s !important`。

各组件样式文件里还有各自的 `@media (prefers-reduced-motion: reduce)` 块。新增动画时必须同时写好对应的降级。

## 9. 主题模式

- 三态：浅色、深色、跟随系统。`localStorage` 键为 `yggdrasil-theme`（值 `light` / `dark`；选择跟随系统时删除该键）。
- 首屏防闪烁：`THEME_PRELOAD_SCRIPT` 在 `<head>` 内联执行，写入 `<html data-theme-mode>` 并切换 `.dark`；`THEME_SEGMENT_STYLE` 根据 `data-theme-mode` 在水合前点亮分段控件的选中项。
- 深色模式靠 `@custom-variant dark (&:where(.dark, .dark *))` 与 `.dark` 覆盖 token 实现；rustdoc 文档的 `data-theme="dark"` 共用同一组深色值。
- `<meta name="theme-color">` 浅色为 `#f5f5f3`，深色为 `#0f0f0e`。
